# 架构与数据流

## 系统组成

```
                    ┌──────────────── 视觉主机（本仓库） ────────────────┐
                    │                                                   │
  传送带 + 编码器 ──►│  SimCamera(硬触发锁存C0) ─► 感知(定位/缺陷)         │
                    │        │                              │           │
                    │        ▼                              ▼           │
                    │   九点/手眼标定                    6D位姿/缺陷/抓取点 │
                    │        │                              │           │
                    │        ▼                              │           │
                    │   基座系位姿(x,y,angle) ───────────────┤           │
                    │                                     ▼           │
                    │                         Modbus TCP Client ────────┼──► PLC(Server)
                    │                                     │             │
                    │                                     ▼             │
                    │                         MQTT 旁路 ──► 孪生引擎(Three.js)
                    └───────────────────────────────────────────────────┘
```

- **PLC 是产线主控**，视觉主机是 Modbus **Client**，通过点表寄存器握手。
- **相机硬触发**：触发瞬间锁存编码器值 C0，把曝光与皮带位置锁死。
- **机器人伺服走 EtherCAT**（运动控制级，本仓库视觉侧不涉及，只输出目标位姿）。
- **孪生走 MQTT 旁路只读镜像**，不写回任何设备。

## 视觉单帧数据流

1. 触发 → 相机成像 + 锁存编码器 C0。
2. 预处理（灰度/去噪/阈值）。
3. 定位：OpenCV 轮廓 + 最小外接矩形（中心/角度/类别），或 YOLO 粗框 + OpenCV 精修。
4. 九点标定映射：像素 (u,v,θ) → 基座系 (X,Y,θ)。
5. 缺陷检测：PatchCore 无监督异常检测（正常样本训练，memory bank 最近邻打分）。
6. 按点表写 Modbus：XYZ/角度/编码器 C0/结果码，置 DONE。
7. 机器人/PLC 用计数差 `(C1-C0)/pulses_per_mm` 补偿皮带位移后抓取。
8. 位姿/缺陷/抓取点经 MQTT 旁路推送孪生，虚实同步。

## 坐标系

- **基座系**：传送带平面 Z=0，X 沿皮带运动方向，Y 垂直皮带，单位 mm。
- **图像系**：像素 (u,v)，原点左上。
- **九点标定**：图像 (u,v) ↔ 基座 (X,Y) 的单应映射（固定俯视相机）。
- **手眼标定**：AX=XB，X = 相机在夹爪系的固定变换（eye-in-hand，用于相机装在末端/复核场景）。
